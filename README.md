# IEEE-CIS Fraud Detection

Educational fraud classification project.

## Selected Model
HistGradientBoosting + Fraud Feature Engineering V2

## Validation
ROC-AUC: 0.912001
PR-AUC: 0.534559

## Feature Engineering
144 original features + 16 additional features.

## Streamlit
- Synthetic transaction scoring
- Batch CSV predictions
- Saved historical frequency statistics
- Shared feature engineering module

The CSV input must contain the original
engineered features expected by the model.

## Disclaimer
Educational use only.
No real personal, financial or payment data.
Not suitable for real fraud decisions.
